## 📌 3. Notes & Work Standards (Quy chuẩn thực hiện)

1. **Git Workflow:** Mỗi công việc trên đây tương ứng với 1 Issue trên GitHub. Khi làm việc, thành viên tạo branch dạng `feature/issue-ID` (ví dụ: `feature/issue-8`) và tạo Pull Request (PR) để người khác review trước khi merge[cite: 1, 2].
2. **Cập nhật trạng thái:** Cập nhật trạng thái từ `In Progress` sang `Completed` trên GitHub Projects ngay khi hoàn thành task.
